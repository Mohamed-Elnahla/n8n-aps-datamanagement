# Code of Conduct

## Our standard

Contributors and maintainers must communicate respectfully, welcome constructive feedback, and focus discussion on improving the project. Harassment, discrimination, personal attacks, publishing private information, and disruptive behavior are not acceptable.

## Enforcement

Project maintainers may edit, remove, or reject contributions and may temporarily or permanently restrict participation when behavior violates this standard.

## Reporting

Report conduct concerns privately through the repository owner's GitHub profile contact options. Do not use public issues for sensitive conduct reports.

This code of conduct applies in repository issues, pull requests, discussions, and other project spaces.
