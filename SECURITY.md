# Security policy

## Supported versions

Security fixes are applied to the latest published version. Users should update before reporting a problem that may already be fixed.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability involving credential exposure, authentication bypass, arbitrary code execution, or unauthorized ACC access.

Use GitHub's **Security → Report a vulnerability** private reporting feature for this repository. Include:

- A concise impact statement.
- A minimal reproduction.
- Affected versions.
- Suggested remediation, if known.

Do not include live APS secrets, access tokens, signed URLs, or customer data. Revoke or rotate any credential that may have been exposed before sending the report.

## Scope

This policy covers code maintained in this repository. Vulnerabilities in Autodesk services, n8n itself, npm, GitHub Actions, or other third-party infrastructure should also be reported to the appropriate vendor.
